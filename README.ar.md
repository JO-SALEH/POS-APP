## لماذا؟

الصيدلية لا تتوقف عن البيع لأن الكمبيوتر مشغول أو الواي فاي انقطع. **JØ PHARMA MOBILE** يحوّل أي هاتف أندرويد إلى كاشير كامل: مسح بالكاميرا، بيع بالعبوة أو الشريط أو الحبة، نقداً أو بطاقة أو محفظة أو آجل، ومشاركة الإيصال، ثم يلحق الهاتف ببرنامج JØ PHARMA على الكمبيوتر لاحقاً **دون ضياع أي فاتورة أو تسجيلها مرتين**.

بدون حساب، بدون سحابة، بدون إنترنت.

## المميزات

- **البيع:** مسح مستمر بالكاميرا، قارئ باركود خارجي، بحث بالاسم أو بأي باركود، إضافة سريعة لباركود غير معروف، تعليق الفواتير واستدعاؤها، تراجع.
- **الوحدات:** بيع بالعبوة أو الشريط أو الحبة بسعر تلقائي، والمخزون يُخصم بالحبات.
- **الدفع:** نقد / بطاقة / محفظة / **آجل**، اسم العميل، خصم بالمبلغ أو النسبة، ضريبة، المبلغ المستلم والباقي.
- **الأمان:** منع بيع المنتهي الصلاحية، تنبيه القريب من الانتهاء، تأكيد عند نقص المخزون، تنبيه حد إعادة الطلب.
- **العملاء الآجل:** اقتراح الأسماء ورصيد العميل المتزامن من الكمبيوتر.
- **المرتجعات:** جزئية ومحدودة بما بيع، تعيد المخزون وتصل للكمبيوتر تلقائياً.
- **الورديات والتقارير:** فتح وإغلاق الوردية بجرد النقد والفرق، مبيعات اليوم، طرق الدفع، الأكثر مبيعاً، النقص، القريب من الانتهاء.
- **الصلاحيات:** حساب مدير وحساب كاشير.
- **المنتجات:** استيراد من قاعدة JØ PHARMA أو Excel أو CSV أو JSON مع اكتشاف الأعمدة وشاشة ربط بمعاينة، تحديد متعدد وحذف وتعديل أسعار جماعي وتصدير.
- **الربط بالكمبيوتر:** اقتران بـ QR، إرسال تلقائي للفواتير والمرتجعات، وتحديث المنتجات والأسعار والمخزون والصلاحية.
- **الواجهة:** تصميم أسود وذهبي، عربي (من اليمين لليسار) وإنجليزي.

## التحميل والتثبيت

1. حمّل [`JO_POS.apk`](https://github.com/JO-SALEH/POS-APP/releases/latest/download/JO_POS.apk) على هاتفك (حوالي 71 ميجا).
2. افتحه واسمح بـ «التثبيت من مصادر غير معروفة» إن طلب أندرويد.
3. ادخل بـ `admin` / `1234` وغيّرها من الإعدادات ← الحساب.

يحتاج أندرويد 7.0 أو أحدث وكاميرا للمسح.

## كيف يعمل

كل عملية بيع تُكتب أولاً في قاعدة SQLite على الهاتف، والمزامنة تتم في الخلفية. لكل فاتورة ومرتجع معرّف ثابت، فإعادة المحاولة بعد انقطاع الرد لا تسجّل مرتين. التفاصيل مع مقاطع الكود في [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## البناء والاختبار

```bash
flutter create . --platforms=android --project-name jo_pos_mobile
python3 tools/patch_android.py
flutter pub get
flutter test test_importer
flutter build apk --release
```
