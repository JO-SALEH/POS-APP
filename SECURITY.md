# Security policy

## Reporting a vulnerability
Please **do not** open a public issue for a security problem. Use GitHub's private reporting instead: *Security → Report a vulnerability* on this repository. Include what you found, the steps to reproduce it, and the app version.

You will get an answer as soon as possible. Please give a reasonable time to fix the problem before disclosing it publicly.

## Supported versions
Only the latest release receives fixes.

## Good practice for users
- Download the app only from this repository's *Releases* page and compare the SHA-256 in the release notes.
- Change the default password (`admin` / `1234`) at first launch.
- Use a trusted Wi-Fi for the PC link, and generate a new QR on the PC if a phone is lost or a QR was shown to someone.
- Keep regular backups of the database.
